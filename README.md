# WorkflowGen AI

AI-Powered Documentation and Process Automation System that transforms raw information into structured reports, SOPs, summaries, and business documents.

## Features

- Meeting notes summarization
- SOP generation
- Report generation
- Follow-up email generation
- Workflow templates
- Documentation automation

## Tech Stack

- Python
- Streamlit
- Pandas
- OpenAI API / Gemini API
